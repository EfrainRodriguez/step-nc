# Code of Conduct

## 1. Purpose

The goal of this project is to foster a collaborative, inclusive, and professional environment.  
Everyone participating in this project—maintainers, contributors, and users—is expected to act with respect, integrity, and fairness.

This Code of Conduct outlines the standards of behavior that help us maintain a productive and welcoming community.

---

## 2. Our Standards

### Positive behaviors include:
- Showing respect, kindness, and empathy toward other participants.
- Providing constructive feedback and being open to receiving it.
- Using inclusive and professional language.
- Helping create a safe environment for people from all backgrounds, expertise levels, and professional fields.
- Focusing on collaboration instead of competition.

### Unacceptable behaviors include:
- Harassment, discrimination, or insulting comments.
- Personal attacks, trolling, or intentionally disruptive behavior.
- Publishing private information without explicit permission.
- Any conduct that could be considered inappropriate, unsafe, or unprofessional.
- Aggressive or dismissive communication.

---

## 3. Responsibilities of Maintainers

Project maintainers are responsible for:
- Reviewing contributions in a fair and timely manner.
- Clarifying the standards of acceptable behavior.
- Taking appropriate action when unacceptable behavior occurs.
- Ensuring that this Code of Conduct is applied consistently and impartially.

Maintainers may remove, edit, or reject comments, commits, code, issues, or pull requests that violate this Code of Conduct.

---

## 4. Scope

This Code of Conduct applies to all project spaces, including:
- GitHub issues, discussions, and pull requests
- Community channels
- Project documentation
- Any interactions representing the project or its community

It also applies when individuals are officially representing the project outside its official spaces (e.g., conferences, academic events, workshops).

## 6. Enforcement

If a participant engages in unacceptable behavior, maintainers may take any of the following actions:

- Provide a formal warning.
- Remove comments, code, or contributions related to the violation.
- Temporarily or permanently ban the contributor from project spaces.
- Revoke access or privileges within the repository.

Enforcement decisions will be made responsibly, fairly, and consistently.
