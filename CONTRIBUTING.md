# Contributing Guide

Thank you for your interest in contributing to this project!  
We welcome contributions of all kinds, including code, documentation, tests, and ideas.

This document provides a simple overview of how to get started.

---

## 1. How to Contribute

There are several ways to contribute:

- Fix bugs or report issues  
- Improve documentation  
- Add tests or enhance existing ones  
- Implement new features  
- Refactor or improve code quality  
- Propose ideas or improvements

If you are unsure whether something is a good fit, feel free to open an issue first.
