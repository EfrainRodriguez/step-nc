# Roadmap - @step-nc/step-factory

## Current status

- Core runtime model (`StepModel`) is implemented.
- Attribute/reference/select/aggregation primitives are implemented.
- Validation layers (instance/model/where/unique) are implemented.
- Expression interpreter and derived-attribute support are implemented.

## Next priorities

- Continue hardening edge-case behavior and diagnostics.
- Expand complex multi-schema and inverse-reference scenarios.
- Add more high-scale performance and memory regression tests.

## Future ideas

- Extended hooks/events for runtime lifecycle integrations.
- Additional optimization passes for large models.
