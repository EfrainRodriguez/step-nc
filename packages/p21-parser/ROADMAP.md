# Roadmap - @step-nc/p21-parser

## Current status

- Lexer and parser for ISO 10303-21 are implemented.
- Typed AST and diagnostics are implemented.
- Visitor/walker traversal APIs are implemented.

## Next priorities

- Strengthen error recovery for malformed files.
- Add more real-world fixture coverage (including large files).
- Improve parser performance profiling and memory baselines.
- Expand conformance-oriented regression tests.

## Future ideas

- Additional strictness modes for validation-sensitive workflows.
- Tooling utilities around AST debug output and inspection.
